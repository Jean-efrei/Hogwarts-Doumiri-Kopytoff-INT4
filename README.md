# Hogwarts game !
## Description:

this project consists of developing an interactive adventurous game in Python, in Harry Potter's universe. The goal is to make your house win.

   - menu.py

## Main Features:
 - Creation and management of a character (attributes, inventory, spells) 
 - Interactive choice system influencing the story 
 - Automatic distribution in a Hogwarts house 
 - Learning random spells
 - Magic quiz with point allocation 
 - Complete simulation of a Quidditch match 
 - House point management 
 - Use of JSON files for game data 

## Usage: 
Run the main.py file and launch the program to start the adventure
